# Captures d'écran réelles

Les captures de ce dossier ont été réalisées sur l'application de production
https://carzone-sarl.vercel.app avec des comptes de démonstration temporaires.

- Viewport : 1600 x 1000.
- Thème : sombre CARZONE.
- 67 fichiers PNG, classés par rôle.
- Captures de communication : cloche de notifications, configuration micro/audio/notifications et messagerie/appels.
- Chaque dossier de rôle contient : écran de connexion, tableau de bord ou menu, puis 1 à 2 écrans métier.
- Les comptes utilisés pour les captures ont été supprimés après la session.

Les noms de fichiers correspondent aux renvois des fiches de rôle et des présentations. Les
captures ne contiennent aucun mot de passe saisi.
