## Règle de lecture

- Un rôle ne voit que les modules autorisés par ses permissions.
- Si un module n'apparaît pas dans le menu, le rôle ne doit pas l'ouvrir par URL directe.
- Les procédures de notification, de micro et d'appels sont obligatoires pour tous les rôles qui utilisent les communications internes.
- Les cas d'annulation, de facturation et de données clients doivent être validés par la direction avant la formation officielle.
