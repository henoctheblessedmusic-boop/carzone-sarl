# Checklist de vérification avant livraison

## Contenu & preuves
- [ ] Chaque affirmation est vérifiable ou fournie par le client
- [ ] Aucun faux avis, faux chiffre, fausse certification
- [ ] Les témoignages ont une autorisation d'usage
- [ ] Les mentions légales / politique de confidentialité existent
- [ ] Le formulaire recueille un consentement explicite

## Conversion
- [ ] Promesse visible sans scroller
- [ ] CTA principal présent dans le premier écran
- [ ] CTA sticky mobile (canal prioritaire)
- [ ] Preuve sociale et réassurance à proximité des CTA
- [ ] Formulaire court, messages d'erreur et de succès clairs
- [ ] Numéro WhatsApp/e-mail cliquables

## Qualité technique
- [ ] `typecheck` + `build` OK
- [ ] Captures desktop (1440) et mobile (390)
- [ ] Pas de débordement horizontal
- [ ] Contrastes AA, focus visible, labels de formulaire
- [ ] Pas de dégradation des performances (images optimisées)

## Mesure
- [ ] Événements de conversion en place
- [ ] Baseline avant modification conservée
- [ ] Période de comparaison définie
- [ ] Rapport avant/après rédigé
